# Contributing

This is a personal tool that is open for others to use and learn from.

- **Feedback and ideas:** Open a [GitHub issue](https://github.com/dchong1/rss-to-notion/issues). Describe what you tried, what you expected, and your environment (Python version, mode `rss`/`exa`, relevant config) if reporting a bug.
- **Pull requests:** Small, focused changes are welcome. For larger features, open an issue first so we can agree on direction.

No contributor license agreement is required.
